Personal file transfer utility

h3-transfer

h3-transfer is a personal utility operated by Siyuan Yang. It uses Google Drive as temporary storage to move files between computers configured by the operator, with rclone handling uploads and downloads.

How it works

The operator authorizes a Google account, uploads selected files to Drive, and retrieves those files on a destination computer. Transfer files can be removed from Drive when they are no longer needed.

Limited Drive access

The app requests https://www.googleapis.com/auth/drive.file. This permits access to files created by the app or explicitly made available to it. It does not request access to every file in the account.

This is a personal tool, with no public registration or hosted upload form. This website provides app information; authorization takes place on Google's website.
